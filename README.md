# Global Inequality Analysis

Data analysis project exploring global inequality and its relationship with economic and social indicators.

## Project Overview

This project analyzes global inequality using the **Gini Index** and explores its relationship with:

- GDP per capita  
- Human Development Index (HDI)  
- Education (average years of schooling)  

The goal is to understand the main drivers of inequality and how it evolves across countries and regions over time.

## Tools & Technologies

- Python (Pandas, Matplotlib, Seaborn, Statsmodels) 
- Power BI 

## Key Analyses

- Correlation analysis between inequality, GDP, HDI, and education  
- Linear regression models to quantify relationships  
- Time series analysis (global and regional trends)  
- Comparative analysis across regions  
- Interactive dashboard for data exploration  

## Key Insights

- Inequality is negatively correlated with GDP per capita, HDI, and especially education  
- Education shows the strongest relationship with inequality among the variables analyzed  
- Global inequality has generally decreased over time, though not uniformly  
- Significant regional differences persist, with South and North America showing higher inequality levels  
- Economic growth alone does not guarantee lower inequality
