# Projeto de Análise de Desigualdade Global

## Objetivo

Analisar a desigualdade económica entre países ao longo do tempo e compreender a sua relação com fatores como rendimento (PIB per capita), desenvolvimento humano e educação.


## Perguntas-chave

1. Como evoluiu a desigualdade global ao longo do tempo?
2. Existem diferenças significativas entre regiões?
3. Qual é a relação entre desigualdade e PIB per capita?
4. Países com maior nível de educação apresentam menor desigualdade?
5. O desenvolvimento humano (HDI) está associado a níveis mais baixos de desigualdade?
6. Quais países/regiões apresentam os melhores e piores cenários?
7. Que tendências podem ser observadas ao longo dos anos?

## Datasets

O projeto utiliza quatro fontes principais:

- Gini Index (desigualdade económica)
- GDP per capita (World Bank)
- Human Development Index (HDI)
- Years of Schooling (educação)

Os dados serão integrados com base em:

- country  
- year  

## Ferramentas

- Python → limpeza, integração e análise de dados  
- Power BI → visualização e dashboard  

## Metodologia

1. Limpeza e padronização dos datasets  
2. Integração dos dados (merge por país e ano)  
3. Análise exploratória  
4. Cálculo de correlações entre variáveis  
5. Aplicação de regressão linear simples  
6. Análise temporal da desigualdade  
7. Construção de dashboard interativo  

## Análises previstas

- Evolução do índice de Gini ao longo do tempo  
- Comparação entre regiões  
- Relação entre PIB per capita e desigualdade  
- Relação entre educação e desigualdade  
- Relação entre HDI e desigualdade  

## Métricas principais

- Gini Index  
- GDP per capita  
- Human Development Index (HDI)  
- Years of Schooling  

## Resultado esperado

Identificar padrões globais de desigualdade e compreender os principais fatores associados, contribuindo para uma análise mais profunda das disparidades económicas entre países.

# Global Inequality Analysis Project

## Objective

Analyze economic inequality across countries over time and understand its relationship with key socio-economic factors such as income (GDP per capita), human development, and education.

## Key Questions

1. How has global inequality evolved over time?
2. Are there significant differences between regions?
3. What is the relationship between inequality and GDP per capita?
4. Do countries with higher education levels exhibit lower inequality?
5. Is Human Development Index (HDI) associated with lower inequality?
6. Which countries/regions perform best and worst?
7. What trends can be observed over time?

## Datasets

The project uses four main data sources:

- Gini Index (economic inequality)
- GDP per capita (World Bank)
- Human Development Index (HDI)
- Years of Schooling

Data will be integrated using:

- country  
- year  

## Tools Used

- Python → data cleaning, integration, and analysis  
- Power BI → visualization and dashboard  

## Methodology

1. Data cleaning and standardization  
2. Dataset integration (merge by country and year)  
3. Exploratory data analysis  
4. Correlation analysis between variables  
5. Simple linear regression  
6. Time series analysis of inequality  
7. Development of an interactive dashboard  

## Planned Analysis

- Evolution of Gini index over time  
- Regional comparisons  
- Relationship between GDP per capita and inequality  
- Relationship between education and inequality  
- Relationship between HDI and inequality  

## Key Metrics

- Gini Index  
- GDP per capita  
- Human Development Index (HDI)  
- Years of Schooling  

## Expected Outcome

Identify global inequality patterns and understand the key factors associated with economic disparities across countries, enabling deeper and more informed analysis.
